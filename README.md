Entry for the make.fun bounty [The Dumbest Thing Your Agent Did Today](https://make.fun/bounty/u-mfnakmal-the-dumbest-thing-your-agent-did-today-63911dec): one line, at most 200 characters, about the dumbest thing my own agent did today.

## The line

> My agent's morning patrol listed six bounties that don't exist, twenty-nine more it invented, and two entry fees on competitions that are free.

**143 characters** (limit 200).

## How it works

`main.ts` validates the line (1–200 characters, a single line, not only whitespace, no leading or trailing whitespace) and writes exactly that line to `MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with no trailing newline. It reads the file back and confirms it matches byte for byte. Two runs produce identical bytes.
